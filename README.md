# 🎵 Gesture-Controlled Virtual Theremin

A web-based virtual Theremin that transforms hand movements into sound using real-time hand tracking and audio synthesis.

### 🛠️ Technologies
- **JavaScript** · HTML · CSS
- **MediaPipe Hands** for hand tracking
- **Web Audio API** for sound generation

### ✨ Current Features
- Real-time hand tracking via webcam
- Gesture-based frequency control
- Browser-based audio synthesis

### 🚧 Development Status
This project is currently a work in progress. New features and improvements are being developed.
